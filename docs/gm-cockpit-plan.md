## Спайки §8 (порядок и критерий PASS)

Для каждого — real-app E2E на синтетическом Vault (`tests/e2e`, CDP), вывод в `docs/gm-cockpit-matrix.md`.

1. **Двойной клик по узлу.** Слушатель `dblclick` в capture на `.canvas-wrapper`; PASS, если срабатывает на file/text/group-узлах и не ломает штатное редактирование текстового узла (редактор в iframe, см. AC-37b). Иначе — меню + ⌘⇧O.
2. **Стилизация узлов.** CSS-снippet по `.canvas-node.is-selected`. PASS — рамка и иконка типа без JS-записи в DOM узла.
3. **Оверлеи.** Уже работают рядом с контентом Canvas (ADR 2). Проверить PartyDock снизу и NavChip на 1280×800.
4. **Положение/масштаб.** `canvas.setViewport`/`zoomToBbox` — недокументированы; PASS при воспроизводимой точности ±1 px на 1.14.4; fallback — узлы-метки + `focusNode`.
5. **Контрольные точки.** Копирование `.canvas` через `DataAdapter.copy`, восстановление с защитной копией; PASS, если после отката HP/ресурсы идентичны (sidecar не тронут) и Obsidian перечитывает холст без перезапуска.
6. **Выбор узла ↔ заметка.** `canvas.selection` + `file` узла; fallback — frontmatter `gm-id`.
7. **Ширина панели.** Resize-ручка на `.workspace-leaf` вправо; fallback 340/380/420 в настройках.

Дополнительно §9-1: конфликт с Fantasy Statblocks (уже PASS), производительность на 500 узлах (есть perf-стенд).

## Скелет (после спайков)

1. `manifest.json`: `isDesktopOnly: true` только если OSC потребует `dgram`; иначе OSC опциональный модуль.
2. `src/ui/gm-panel/` — view с рельсом, шириной, PinnedCard; рендер на нативном DOM.
3. `styles.css` ← токены `gm.css`; Cormorant Garamond/Inter поставляются в бандле шрифтами (без сети) либо системные fallback.
4. Настройки: поведение двойного клика, ширина панели, Lightkey.

## Риски и вопросы владельцу

1. **Импорт TTG по ссылке.** v1 `docs/verified-integrations.md`: условия TTG запрещают копировать значительные части и кэшировать тексты; endpoint 5e14 не публичный. Реализация возможна только как «пользователь вставил данные/JSON», либо нужно письменное разрешение. Нужно решение.
2. **Lightkey OSC.** Формат адресов и подтверждение доставки — по документации версии пользователя (SPEC §11). Нужна версия Lightkey или образец адресов.
3. **Шрифты.** Лицензии Cormorant Garamond/Inter (OFL) допускают поставку в бандле; размер ~100–300 КБ превысит бюджет 200 КБ — нужно изменить бюджет или грузить из папки плагина.
4. **Бюджет бандла.** Объём SPEC (инвентарь, заклинания, помещения, Lightkey) выйдет за 200 КБ; нужно поднять лимит или разделить `main.js`.
