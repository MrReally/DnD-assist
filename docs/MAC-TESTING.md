**Статус проверки на macOS: NOT_RUN.** В среде разработки Mac нет; плагин проверен на Linux (Obsidian 1.14.4 и 1.7.7). Ниже — как поставить и что именно проверить руками. Сборка — чистый JavaScript без нативных модулей, одинаковая для Apple Silicon и Intel.

## 2. Самый простой путь: демо-хранилище (плагин уже внутри)
1. Двойной щелчок по `GM-Cockpit-Demo-Vault-1.2.1.zip` → папка `GM-Cockpit-Demo`. Перенесите в «Документы».
2. Obsidian → «Открыть папку как хранилище» → `GM-Cockpit-Demo`.
3. Ответьте «Доверять автору», при необходимости выключите «Безопасный режим» (Настройки → Сторонние плагины).
4. Следуйте `ПЕРВАЯ-ПРОВЕРКА.md` в корне хранилища (10–15 минут).
Основное хранилище не трогайте.

## 3. Установка плагина в другое тестовое хранилище
См. `INSTALL.txt` внутри ZIP плагина: распаковать → положить папку `canvas-assist` в `<хранилище>/.obsidian/plugins/` (скрытая папка: Shift+Cmd+. в Finder) → включить плагин. Подключение приключения: открыть Canvas → «Подключить приключение».

## 4. Чек-лист для Mac (отметьте результат; все пункты пока NOT_RUN)
| # | Что проверить | Как | Ожидаемо |
|---|---|---|---|
| 1 | Запуск на вашей архитектуре (Apple Silicon / Intel) | включить плагин | плагин в списке, ошибок нет; в настройках плагина — «Справочник SRD 5.1: 319 заклинаний…» |
| 2 | Двойной клик по узлу | Canvas демо → двойной клик по «Демо Лирель» | справа карточка; текстовый узел при двойном клике редактируется как обычно |
| 3 | Запасной путь, если двойной клик перехвачен системой | выделить узел → ⌘P → «Открыть выбранный объект в GM Cockpit» | та же карточка |
| 4 | Контекстное меню узла | правый клик (или Ctrl+клик) по узлу | пункт «Открыть в GM Cockpit». **Не проверялся автоматически даже на Linux** |
| 5 | Правая боковая панель | открыть/свернуть/изменить ширину | ширина 340/380/420 по размеру окна; тянется за край |
| 6 | Горячие клавиши | Настройки → Горячие клавиши → «Canvas Assist»/«GM Cockpit» → назначить ⌘⇧O и т. п. | команды работают; встроенные контекстные сочетания плагина (`Shift+F/D/H/E/K`, `Shift+Пробел`) срабатывают только на Canvas приключения, не при вводе; запись `Ctrl+…` означает физическую клавишу Control, не ⌘ |
| 7 | Шрифты и читаемость | оценить панель и карточки | Cormorant Garamond/Inter не встроены: используются системные (Georgia/SF) — текст читаем, заголовки serif |
| 8 | Локальные файлы | после закрытия Obsidian: рядом с демо-папкой `Демо-приключение/.canvas-assist-state.json` | файл есть; `.obsidian/plugins/canvas-assist/srd51.json` на месте |
| 9 | Сохранение после перезапуска | изменить HP, выйти ⌘Q, открыть снова | значения на месте |
| 10 | Принудительное завершение | «Завершить принудительно» (⌥⌘Esc) во время боя, открыть снова | бой и HP на месте |
| 11 | Офлайн | выключить Wi-Fi | всё работает (плагин ничего не грузит из сети) |
| 12 | Свет (Lightkey) | см. раздел «Свет» в `docs/limitations.md` | требует вашего Lightkey; порт и глаголы не подтверждены |

## 5. Автоматический smoke на Mac (по желанию, нужен Node)
```
npm ci && npm run release && ./scripts/mac-smoke.sh      # путь к Obsidian: OBSIDIAN_BIN=/Applications/Obsidian.app/Contents/MacOS/Obsidian
```
Тест открывает **временное** хранилище (ваше не затрагивается), создаёт `tests/e2e/out/smoke-darwin.json`. Если результат FAIL — пришлите файл. Сборка и тесты в CI на macOS (**Mac package**) — это проверка «собирается и юнит-тесты проходят», а не проверка интерфейса в Obsidian.

## 6. Если что-то не так
Запишите шаг и что видно на экране; пришлите скриншот и, если можно, файл `Демо-приключение/.canvas-assist-state.json`. Удалить плагин: выключить и удалить папку `canvas-assist` из `.obsidian/plugins`.
