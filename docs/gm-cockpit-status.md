# GM Cockpit — состояние (версия 1.1.0)

Ветка `claude/gm-cockpit-spec-qz2m5e`. Obsidian 1.14.4 (Linux x64, Xvfb), изолированные Vault и профиль. Скриншоты: `docs/evidence/screenshots/<разрешение>/`, JSON: `docs/evidence/gm-cockpit/`.

## Уровни готовности
| Уровень | Статус |
|---|---|
| 1. Рабочий фундамент (панель, Canvas, HP, сохранение, Undo/Redo) | **достигнут** |
| 2. Боевой инструмент (инициатива, NPC, HP, состояния, быстрый доступ) | **достигнут** (ядро боя — v1; карточки участников, «В бой», 20 участников проверены) |
| 3. Основной GM Cockpit (инвентарь, оружие, заклинания, ресурсы, отдых, поиск) | **достигнут** с ограничениями (см. ниже) |
| 4. Полная функциональность (конструктор, импортёры, Lightkey UI, точки обзора, контрольные точки, подготовленные столкновения) | **частично**: всё перечисленное работает; данные SRD ограничены; реального Lightkey не было |
| 5. Качество (E2E, офлайн, восстановление, производительность, визуал, совместимость) | **частично**: Linux/Obsidian 1.14.4, три разрешения; macOS/Windows/мобильные/другие версии Obsidian — NOT_RUN |

## Не реализовано / не подтверждено
См. `docs/limitations.md` (раздел GM Cockpit 1.1.0). Главное: реальный Lightkey, TTG-загрузка (запрещена), полные данные SRD (подклассы/бестиарий/заклинания), классовые правила отдыха сверх HP/ячеек/костей, рельс 40 px и закреплённая вторая карточка, macOS/Windows/мобильные.
