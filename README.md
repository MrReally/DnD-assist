# D&D Canvas Assist

Лёгкий плагин Obsidian для мастера D&D 5e (правила 2014). Работает поверх ваших холстов Canvas и Markdown-заметок: поиск и навигация по холсту, учёт инициативы, хитов, ресурсов, состояний с таймерами по игровым событиям, подготовленные столкновения, отдых, импорт листов персонажей из JSON. Интерфейс на русском.

**Это не виртуальный игровой стол.** Кубики физические: вы вводите результаты руками. Боевой карты, автоматических бросков и проверки правил нет.

- Работает без интернета, без TTG и без других TTRPG-плагинов.
- Ничего не сканирует фоном, таймеров и сервера нет. В простое плагин не грузит процессор.
- Папки не создаёт. На каждое приключение появляется один служебный файл `.canvas-assist-state.json`.
- В холсты (`.canvas`) не пишет никогда. В Markdown меняет только свой отмеченный блок в листах персонажей.

## GM Cockpit (1.2.0) и справочник SRD 5.1

Панель мастера рядом со штатным Canvas: карточки игроков, NPC, монстров и помещений, инвентарь, заклинания, отдых, конструктор персонажа, быстрый NPC, точки обзора и контрольные точки Canvas, свет Lightkey (OSC). Данные игры лежат в служебном файле приключения; Canvas плагин не переписывает (кроме явного восстановления контрольной точки).

Встроенный справочник — **SRD 5.1 (редакция 2014)** под лицензией CC-BY-4.0, файл `srd51.json` рядом с `main.js`: 319 заклинаний, 318 существ, оружие, доспехи, снаряжение, таблицы классов, расы. Всё, чего нет в SRD (например, предыстория «Преступник»), вводится вручную или JSON — плагин ничего не подставляет из памяти. Атрибуция: `data/srd51/ATTRIBUTION.md`.

## Установка

1. Скачайте `canvas-assist-1.2.0.zip` (раздел Releases) и распакуйте. Получится папка `canvas-assist/` с файлами `manifest.json`, `main.js`, `styles.css`, `srd51.json`.
2. Положите эту папку в `<ваше хранилище>/.obsidian/plugins/`. Итоговый путь: `.obsidian/plugins/canvas-assist/main.js`.
3. В Obsidian откройте «Настройки → Сторонние плагины». Если включён безопасный режим, выключите его, затем включите **D&D Canvas Assist**.

> Перед первым подключением настоящего хранилища сделайте его резервную копию. Плагин тестировался только на синтетическом хранилище.

## Первый запуск: одна команда

1. Откройте любой холст из папки приключения, например `Моё приключение/Холсты/…canvas`.
2. Нажмите в верхней строке **«Подключить приключение»** или выполните команду **«Canvas Assist: Использовать текущий Canvas как приключение»**.
3. Подтвердите корневую папку. Плагин предложит её сам по подпапкам `Холсты/`, `Сюжет/`, `Elements/`, `Images/`, `trash/`.

Все холсты внутри корня используют одно общее состояние. Разные приключения не смешиваются, даже если персонажей там зовут одинаково. При открытии холста другого приключения плагин переключается автоматически.

Персонажи игроков берутся из `Elements/Персонажи`, NPC — из `Elements/NPC`.

## Интерфейс

- **Верхняя строка на Canvas:** приключение, партия, кнопка «Бой» (запуск шаблона или спонтанный бой), раунд, кто сейчас ходит, ◀ ▶, пауза, добавить участника, завершить бой, игровое время, ↶ ↷ (Undo/Redo), статус «сохранено / сохранение… / НЕ сохранено», навигатор, боковая панель. Кнопка ⚔ сворачивает строку.
- **Лента инициативы:** карточки участников с хитами, КД и плашками эффектов («Испуганный · 2 х.»). Клик выбирает **цель**. Выбор цели не меняет того, кто ходит. Через «⋯» или правую кнопку мыши открывается меню: передать ход, урон, лечение, эффект, карточка, инициатива, порядок при равенстве, «выбыл», удалить.
- **Панель цели** внизу: урон, лечение, временные хиты, эффект, карточка.
- **Навигатор** (🔍 или `Shift+F`): поиск по текущему холсту — по заголовкам, тексту, файлам, алиасам и группам. Кириллица, регистр и ё/е не мешают. Есть фильтры «Сюжет / NPC / Лут / Homebrew / Заметки / Игнорировать», 8 недавних переходов, назад/вперёд. Переход центрирует и выделяет узел. Правой кнопкой задаётся тип узла вручную.
- **Боковая панель:** вкладки «Бой» (ввод инициатив, общая инициатива для отмеченных), «Партия» (партии, листы, хиты, ячейки, кости хитов, счётчики, импорт, отдых), «Шаблоны» (столкновения и карточки существ, поиск в справочниках), «Время» (игровые часы, эффекты «требует решения»), «История».

## Горячие клавиши

Работают только на холсте подключённого приключения и не срабатывают, пока вы печатаете (в том числе внутри узла Canvas). Клавиши определяются по физической кнопке, поэтому работают и в русской раскладке. Переназначить их можно в настройках плагина. Все действия есть и как команды Obsidian.

| Действие | По умолчанию |
|---|---|
| Поиск по холсту | `Shift+F` |
| Урон выбранной цели | `Shift+D` |
| Лечение | `Shift+H` |
| Эффект | `Shift+E` |
| Карточка цели | `Shift+K` |
| Следующий ход | `Shift+Space` |
| Предыдущий ход | `Shift+Alt+Space` |

Одиночный пробел не назначен: Canvas использует его для перемещения холста.

## Бой

1. **Шаблон** («Шаблоны → Новый шаблон»): название, «включить партию», участники с количеством, хитами, КД, модификатором инициативы, ссылкой на TTG или заметку NPC. Галочка «Общая инициатива группы» объединяет копии одного существа в группу. Шаблон при запуске не меняется. Каждый запуск создаёт новые ID.
2. **Спонтанный бой:** «Бой → Спонтанный бой…» или «+». Кнопка «Подставить из справочника» берёт параметры из ваших карточек, из локального JSON-справочника или из Fantasy Statblocks, если он включён.
3. Введите инициативы по физическим броскам (вкладка «Бой» или клик по числу на карточке) и нажмите **«Начать»**.
4. Пять гоблинов по умолчанию получают пять отдельных инициатив и хитов («Гоблин 1…5»). Общую инициативу задаёте явно. При равенстве порядок стабилен, его можно переставить вручную.
5. Нулевые хиты не удаляют участника. Статус «выбыл» ставится вручную. Удаление из боя требует подтверждения.
6. После завершения боя хиты и ячейки персонажей сохраняются. Эффекты персонажей с боевой длительностью получают статус «требует решения мастера».

## Состояния и длительности

Названия состояний как на TTG Club 2014 (Испуганный, Опутанный, Сбитый с ног…). Можно добавить и свой эффект. У каждого эффекта свои цель, источник и срок. Два «Испуганный» от разных источников — это два независимых эффекта.

Варианты срока:
- без срока;
- **N ходов участника** (начало или конец хода);
- **до следующего хода источника** или другого участника;
- **N раундов**;
- **игровое время** в минутах.

Эффект, наложенный посреди хода, считает только будущие события. Undo и «Предыдущий ход» возвращают истёкшие эффекты. Концентрация — это отметка плюс связанные эффекты: при её снятии плагин предложит снять и связанные. Правила концентрации не проверяются.

## Отдых

На вкладке «Партия» есть «Долгий отдых» и «Короткий отдых». Галочками выбираются персонажи. Профиль «D&D 2014» или «Вручную». Перед применением виден предпросмотр «до → после». Весь отдых — одно действие, его можно отменить.

Счётчики с ручным восстановлением и истощение без вашей отметки не меняются. На коротком отдыхе укажите, сколько потрачено костей хитов и сколько вылечено по броску.

## Импорт персонажей из JSON

Откройте «Партия → Импорт JSON»: выберите `.json` из хранилища или вставьте текст. Плагин покажет предпросмотр, ошибки с путём поля и diff, и только потом записывает. Подробности и пример — в [docs/import-format.md](docs/import-format.md).

## Справочники и TTG

- В карточке существа (`Shift+K`) сразу видны локальные параметры. Кнопка «Открыть на TTG» открывает страницу 5e14.ttg.club в браузере.
- Локальный справочник: путь к вашему JSON внутри хранилища (настройки → «Локальный JSON-справочник»).
- «Онлайн-поиск TTG (экспериментально)» по умолчанию **выключен**. Он работает только по явному запросу в панели и возвращает название и ссылку. Без интернета всё остальное работает как обычно.
- Fantasy Statblocks подключается по флагу в настройках и необязателен.

## Сохранность данных

- Каждое действие записывается на диск до того, как интерфейс покажет «сохранено». Если запись не удалась, появится «НЕ сохранено», а действие не применится.
- Undo/Redo хранит последние 100 действий или 256 КиБ и работает одинаково на всех холстах приключения, в том числе после перезапуска. Повтор одного и того же действия не удваивает урон.
- Если файл состояния изменили извне (синхронизация, второе устройство), плагин показывает **«Конфликт версий»**. Перед выбором версии обе копии сохраняются.
- Если файл повреждён, включается режим «только чтение». Оригинал не трогается, создаётся копия.
- При обновлении схемы сначала делается резервная копия, потом миграция.
- Переименование и перенос папок отслеживаются. Скопированная папка приключения не смешивается с оригиналом.
- После выключения плагина холсты и заметки открываются в Obsidian как обычно.

## Известные ограничения

См. [docs/limitations.md](docs/limitations.md). Главное:
- проверено на Obsidian 1.14.4 desktop (Linux);
- мобильные устройства, macOS и Windows в реальном приложении не тестировались (NOT_RUN);
- фокус на узле опирается на недокументированный API Canvas. Если он изменится, включится запасной путь.
