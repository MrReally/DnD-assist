# Changelog

## 1.1.0 — GM Cockpit (2026-11-25)

Расширение Canvas Assist пультом мастера. Схема состояния не менялась (v2): новые данные лежат в `extensions.cockpit`, v1.0.0 обновляется без миграции (проверено E2E J).

- **Панель GM Cockpit** (правая боковая, 340/380/420 px по размеру экрана): карточки PC, NPC и монстров (компактная и полная), справочные карточки помещений, оружие, предметы, заклинания. Двойной клик по узлу Canvas, команда «Открыть выбранный объект в GM Cockpit» и пункт меню узла; штатное поведение Canvas для остальных узлов не меняется.
- Правка HP одним полем (`−7`, `+5`, `=12`), КД, листы персонажей (характеристики, спасброски, навыки), Undo/Redo, панель партии.
- **Инвентарь**: экземпляры предметов отдельно от типов (SRD 5.1: оружие, доспехи, снаряжение), количество, цена, вес, контейнеры, передача, монеты; бонус атаки и урон считаются по характеристикам и владениям с разбором «Как считается».
- **Быстрый NPC** по описанию («Гоблин-посетитель таверны с кинжалом») на шаблонах SRD, «Создать и в бой».
- **Конструктор персонажа** (раса, класс, уровень, характеристики, навыки, снаряжение; быстрое заполнение с бумажного листа; повышение уровня).
- **Заклинания**: локальная библиотека, импорт JSON/вручную/по названию, известные и подготовленные, ячейки, концентрация, использование с выбором ячейки одним Undo.
- **Lightkey (OSC)**: настройки, привязка cue к заклинанию, кнопка «Свет ▶», необязательный автозапуск, тестовая отправка. Успешная отправка не считается подтверждением.
- **Canvas**: точки обзора 1–9 и возврат, контрольные точки с защитной копией (игровое состояние не откатывается), поиск «Перейти» с явным добавлением на Canvas.
- Бандл 315 КБ (потолок 500 КиБ). Шрифты не встраиваются.

## 1.0.0 — 2026-10-18

Первый релиз.

- Подключение приключения одной командой. Несколько приключений изолированы друг от друга, все холсты одного приключения используют общее состояние. Отслеживаются переименования и копии папок.
- Навигатор по текущему Canvas: русский поиск (регистр, ё/е), категории Сюжет/NPC/Лут/Homebrew/Заметки/Игнорировать, ручной тип узла, недавние переходы, назад/вперёд, фокус на узле с запасным путём.
- Бой:
  - шаблоны столкновений и спонтанный бой;
  - уникальные участники, индивидуальная или явная общая инициатива, стабильный порядок при равенстве;
  - раунды, пауза, переход к участнику;
  - урон, лечение и временные хиты ручным вводом;
  - выбранная цель отделена от того, кто ходит.
- Эффекты: состояния TTG 2014 и свои эффекты; таймеры по игровым событиям (ходы, «до следующего хода», раунды, игровое время); концентрация; статус «требует решения мастера».
- Отдых: долгий и короткий для выбранных персонажей, профиль 2014 или ручной, предпросмотр, одно отменяемое действие.
- Импорт JSON со строгой валидацией и предпросмотром. Лист записывается в управляемый блок Markdown; повторный импорт сохраняет текущие ресурсы.
- Единая история действий с Undo/Redo и идемпотентностью; запись с проверкой ревизии; режим восстановления; миграция схемы v1→v2 с резервной копией.
- Справочники: ссылки TTG, локальный JSON, опциональный онлайн-поиск TTG (выключен), опциональный Fantasy Statblocks.
- Реальный E2E на Obsidian 1.14.4, бюджеты производительности, release ZIP.
