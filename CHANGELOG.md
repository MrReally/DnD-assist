# Changelog

## 1.0.0 — 2026-10-18

Первый релиз.

- Подключение приключения одной командой. Несколько приключений изолированы друг от друга, все холсты одного приключения используют общее состояние. Отслеживаются переименования и копии папок.
- Навигатор по текущему Canvas: русский поиск (регистр, ё/е), категории Сюжет/NPC/Лут/Homebrew/Заметки/Игнорировать, ручной тип узла, недавние переходы, назад/вперёд, фокус на узле с запасным путём.
- Бой:
  - шаблоны столкновений и спонтанный бой;
  - уникальные участники, индивидуальная или явная общая инициатива, стабильный порядок при равенстве;
  - раунды, пауза, переход к участнику;
  - урон, лечение и временные хиты ручным вводом;
  - выбранная цель отделена от того, кто ходит.
- Эффекты: состояния TTG 2014 и свои эффекты; таймеры по игровым событиям (ходы, «до следующего хода», раунды, игровое время); концентрация; статус «требует решения мастера».
- Отдых: долгий и короткий для выбранных персонажей, профиль 2014 или ручной, предпросмотр, одно отменяемое действие.
- Импорт JSON со строгой валидацией и предпросмотром. Лист записывается в управляемый блок Markdown; повторный импорт сохраняет текущие ресурсы.
- Единая история действий с Undo/Redo и идемпотентностью; запись с проверкой ревизии; режим восстановления; миграция схемы v1→v2 с резервной копией.
- Справочники: ссылки TTG, локальный JSON, опциональный онлайн-поиск TTG (выключен), опциональный Fantasy Statblocks.
- Реальный E2E на Obsidian 1.14.4, бюджеты производительности, release ZIP.
